# 🤝 InAmigos Foundation

An interactive, single-page web application for **InAmigos Foundation** designed to boost donor engagement and streamline volunteer onboarding.

## ✨ Features

* **Donation Impact Calculator:** Dynamic slider and preset tiers showing real-time impact (meals, school kits, saplings) with an instant 80G receipt flow.
* **Volunteer Badge Wizard:** 3-step signup modal that generates a downloadable digital volunteer badge.
* **Before & After Slider:** Interactive split-screen comparator showcasing real rescue and community transformations.
* **Filterable Causes & Gallery:** Category-based filtering with live fundraising progress bars and a fullscreen photo lightbox.
* **Event RSVP & Calendar Sync:** Quick event registration with Google Calendar and `.ics` download links.
* **Sahayak AI Chatbot:** Floating 24/7 assistant for donor, rescue, and volunteering FAQs.
